# Traubali Clone Website

A modern, responsive frontend recreation of the official Taru Bali website built using React, Vite, and Tailwind CSS.  
This project focuses on premium UI/UX, smooth animations, immersive scrolling effects, and modern web interactions.

## 🚀 Live Inspiration

Original Website: https://tarubali.com/

## 📌 Project Overview

This project is a pixel-perfect frontend recreation of the Taru Bali website with:

- Smooth scrolling animations
- Floating and rotating bottle animation
- Premium luxury-style UI
- Responsive navbar with scroll effects
- Interactive hover menus
- Modern layout sections
- Fully responsive design
- High-quality visual experience

The goal of this project is to practice advanced frontend development and animation techniques used in modern premium-brand websites.
